Tools that pair well with zshbop. Each one is optional; none is installed by the guided installer.

## ssh-audit

Audits an SSH server or client configuration.

```bash
snap install ssh-audit
```

- Upstream: [jtesta/ssh-audit](https://github.com/jtesta/ssh-audit)

## lsd

A modern replacement for `ls`, with icons, colours, and tree output.

- Upstream: [Peltoche/lsd](https://github.com/Peltoche/lsd)
