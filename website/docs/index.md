zshbop is a custom Zsh configuration: a prompt, aliases, checks, and commands that turn a fresh
shell into a working one on Linux, macOS, and WSL hosts.

Start with [What zshbop is](./getting-started/what-is-zshbop.md), then try the completion flow in
[Tab completion](./guides/tab-completion.md).
